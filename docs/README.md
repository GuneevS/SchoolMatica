# SchoolMatica Documentation Hub

This `/docs` directory is the canonical reference point for the active product and delivery context. It aggregates the blueprint content that previously lived under `MarkbookSaaS_docs/` and adds working notes for the current build. Always review this folder before starting a task and update it whenever milestones or assumptions change.

Key files:

- `PRODUCT_BLUEPRINT.md` – vision, personas, and functional scope (mirrors `MarkbookSaaS_docs/docs/PRODUCT_BLUEPRINT.md`).
- `CODEX_PROMPT.md` – detailed implementation contract (mirrors `MarkbookSaaS_docs/docs/CODEX_PROMPT.md`).
- `DELIVERY_NOTES.md` – running log of milestones, open questions, and architectural decisions.

> Source of truth: when either the blueprint or prompt is updated here, ensure the equivalent file under `MarkbookSaaS_docs/docs/` stays in sync, or explicitly document divergences.
